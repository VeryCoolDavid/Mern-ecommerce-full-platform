E-Commerce Application

A full-stack e-commerce application built with **React, Node.js, MongoDB, Express and EJS**.

## Features

* **CRUD Operations** — Create, read, update, and delete products.
* **Role-Based Access Control** — Separate access and permissions for users and administrators.
* **Payment Integration** — Secure online payments using **Razorpay**.
* **Product Management** — Manage products, pricing, and inventory.
* **User Authentication** — Secure user authentication and authorization.

## Tech Stack

* **Frontend:** React, EJS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Payments:** Razorpay
